# SolidCraft 中文版 · 打包与发布

## 方式 A：用已编译二进制打包（本机无需 Rust/MSVC，推荐）

前置条件：

- Windows 10/11 x64，PowerShell 7（或 5.1）
- WiX v5：`dotnet tool install --global wix --version 5.0.2`
  `wix extension add -g WixToolset.UI.wixext/5.0.2`
  `wix extension add -g WixToolset.Util.wixext/5.0.2`
- 上游 Windows x64 便携版 zip（内含 `solidcraft.exe`、`solidcraft-cli.exe`、许可证）

命令（仓库根目录）：

```powershell
pwsh zh-cn/packaging/windows/package-zh-cn.ps1 `
  -Version 0.48.2 -UpstreamVersion 0.48.1 `
  -PortableZip E:\AI作品\work\solidFusion\dist\solidcraft-upstream-0.48.1-windows-x64-portable.zip `
  -Dist E:\AI作品\work\solidFusion\dist\release
```

脚本依次：解压到全新 stage → 复制中文增强文件 → 生成 `版本.json` / `更新清单.json` →
WiX 构建中文 MSI → 压缩中文便携版 → 生成稳定名副本、`SHA256SUMS.txt`、`latest.json`。

产物校验：

```powershell
Get-ChildItem .\dist\release | Select-Object Name, Length
Get-Content .\dist\release\SHA256SUMS.txt
wix msi validate .\dist\release\solidcraft-windows-x64.msi -ice ICE50
```

> 打包脚本不删除已有目录，每次用带时间戳的 stage；清理 stage 需手动确认后进行。

## 方式 B：从源码本地编译

上游要求 Rust 1.99.1（`rust-toolchain.toml`）、edition 2024、MSVC x64 工具链：

```sh
cargo build --release --locked -p solidcraft --target x86_64-pc-windows-msvc
cargo build --release --locked -p solidcraft-cli --target x86_64-pc-windows-msvc
pwsh zh-cn/packaging/windows/package-zh-cn.ps1 -BinDir target\x86_64-pc-windows-msvc\release
```

注意 `-BinDir` 模式下需要把 `LICENSE-*`、`NOTICE`、`THIRD-PARTY-LICENSES.txt` 一并放入该目录（脚本会从仓库根补齐）。
上游官方脚本 `packaging/windows/package.ps1 -Arch x64` 也可用于构建英文原版 MSI。

## 方式 C：云端编译并发布（GitHub Actions）

`.github/workflows/release-zh-cn.yml`：

- 触发：手动 `workflow_dispatch`（填 `version`，勾选 `publish`），或推送 `release-zh-cn` 分支（只构建、不发布）；
- 运行器：`windows-latest`（自带 MSVC），`dtolnay/rust-toolchain@1.99.1`；
- 构建：静态 CRT 的 app + CLI，随后调用中文打包脚本；
- 发布：`publish=true` 时用 `gh release create` 建立 `v<version>` 并上传 MSI、便携版、校验表、更新清单；
  资产使用稳定名，`releases/latest/download/` 链接持续有效；
- 权限：`contents: write`。

```sh
gh workflow run release-zh-cn.yml -f version=0.48.2 -f publish=true
```

## 发布到远程的完整动作

1. 提交并推送中文版源码改动（分支 `main` 或 `release-zh-cn`）。
2. 打标签 `v0.48.2`，创建 GitHub Release（非 draft、非 prerelease，才能成为 `latest`）。
3. 上传资产：`solidcraft-windows-x64.msi`、`solidcraft-windows-x64-portable.zip`、
   `SHA256SUMS.txt`、`latest.json`（以及带版本号的副本便于归档）。
4. 验证：
   ```sh
   curl https://api.github.com/repos/wodeya163/solidcraft/releases/latest
   curl -I https://github.com/wodeya163/solidcraft/releases/latest/download/solidcraft-windows-x64.msi
   ```
   应返回 `v0.48.2`，资产列表含稳定名 MSI，且校验表哈希与本地产物一致。

## 版本号约定

- Release 标签用纯数字三段（`v0.48.2`），不带 `-rc`/`-zh` 后缀：内置更新器只把**稳定版**视为可升级目标。
- `Cargo.toml` 的 workspace 版本保持上游值，避免破坏 `Cargo.lock` 与上游同步；
  云端构建通过 `SOLIDCRAFT_VERSION` 把发行版本写进二进制。
