# 源码中文化说明（英文原文 ↔ 中文版）

## 原则

1. **英文原版完整保留**：`assets/locales/en.json`、`crates/ui-text/locales/en.json`、所有英文文档、
   `packaging/windows/package.ps1` 等上游文件一律不改，便于继续 `git fetch upstream && git merge`。
2. **界面文案成中英双版**：所有 message id 同时有英文与简体中文文本；中文版是默认，英文版可一键切回。
3. **源码注释保留英文**：Rust 源码注释是给上游贡献者看的工程文档，逐条翻译会制造上千行无意义 diff；
   中文版另附中文说明文档（本文件、安装/构建说明）作为对照。
4. **新写的中文组件全中文**：安装向导、更新器、启动器、计划任务、发行说明全部中文。

## 补译规则

`zh-cn/i18n/build_zh_cn.py` 只补译「英文原文 = 中文原文」且确实是英文句子的条目（16 条，
例如 `Board thickness must be greater than 0 and at most 1000 mm.`）。
其余 59 条中英同文条目是 `X` / `Y` / `Z`、`HDR`、`STEP`、`{name} · {value}`、`IOR`、
`ISO 4753` 等符号、占位符或行业专名，强行翻译反而会破坏格式串，故保持原文。

重新生成（幂等）：

```sh
python zh-cn/i18n/build_zh_cn.py
```

脚本会校验 en/zh 键集合一致、应用包与共享包无重复 id，然后按行最小改动写回 `assets/locales/zh.json`。

## 源码层的三处改动

| 文件 | 改动 | 原因 |
| --- | --- | --- |
| `crates/ui-egui/src/prefs/fields/general.rs` | 默认语言 `system` → `zh` | 中文定制版首次启动即中文，不依赖系统区域设置；用户已保存的选择仍优先 |
| `crates/ui-egui/src/update.rs` | `REPO` / `LATEST_API` / `RELEASES_PAGE` / `HISTORY` 指向 `wodeya163/solidcraft`，`RELEASE_PREFIXES` 增到 3 个（保留上游两个） | 内置更新器与远程发行版关联；旧链接仍可用 |
| `crates/ui-egui/src/update/tests.rs`、`fonts.rs`、`i18n.rs` | 同步断言 | 保证 `cargo xtask ci` 测试仍通过 |

## 未改的地方（有意为之）

- 上游 GitHub 链接（issue、文档、 attribution）保留原组织名，避免破坏历史链接与归属声明。
- `Cargo.toml` 的 `repository` 字段与 workspace 版本保持上游值，避免 `Cargo.lock` 变动。
- 品牌名 `SolidCraft`、命令 id、文件格式、`.sc` 扩展名、MCP 命令名保持英文（协议/兼容性标识，不是界面文案）。
