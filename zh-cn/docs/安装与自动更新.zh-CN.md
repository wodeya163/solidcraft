# SolidCraft 中文版 · 安装与自动更新

## 一、安装（Windows 10/11 x64）

1. 下载 `solidcraft-windows-x64.msi`（[稳定链接](https://github.com/wodeya163/solidcraft/releases/latest/download/solidcraft-windows-x64.msi)）。
2. 可选校验：下载同版 `SHA256SUMS.txt`，执行
   ```powershell
   Get-FileHash .\solidcraft-windows-x64.msi -Algorithm SHA256
   ```
   与表中 `solidcraft-windows-x64.msi` 一行比对。
3. 双击 MSI，按中文向导安装（默认 `C:\Program Files\SolidCraft`）。需要管理员权限（per-machine 安装）。
4. 开始菜单新增两项：
   - **SolidCraft 中文版**：写入中文偏好 → 启动主程序 → 后台检查更新；
   - **检查 SolidCraft 更新**：手动检查并可选择立即升级。
5. 静默安装：`msiexec /i solidcraft-windows-x64.msi /qn /norestart`。

绿色版：解压 `solidcraft-windows-x64-portable.zip`，运行目录中的 `启动中文版.ps1` 或直接运行 `solidcraft.exe`。

## 二、中文界面

- 中文版默认 `zh`，源码默认值见 `crates/ui-egui/src/prefs/fields/general.rs`。
- 启动器会在首次运行时写 `%APPDATA%\SolidCraft\data\app.ron`，把 `solidcraft.prefs` 的 `language` 设为 `zh`；**已有其它语言设置时不覆盖**。
- 「首选项 → 常规 → 语言」可随时切回英文原版（`en`）或跟随系统（`system`）。
- 内置简体中文语言包 7764 条界面文案 + 254 条共享文案，另保留 `zh-TW` 繁体。

## 三、自动更新（与远程关联）

| 触发方式 | 行为 |
| --- | --- |
| 从「SolidCraft 中文版」启动 | 后台静默检查 `wodeya163/solidcraft` 的 `releases/latest`；有新版本且程序未运行时下载、校验并 `/passive` 升级 |
| 开始菜单「检查 SolidCraft 更新」 | 弹中文窗口，由用户确认后升级；已是最新版会明确提示 |
| 每日计划任务 | 以管理员运行安装目录里的 `注册每日自动更新.ps1`；默认每天 10:00 只检查并记录日志，加 `-AutoInstall` 则自动升级 |
| 内置更新器（源码重编译版本） | `crates/ui-egui/src/update.rs` 直接请求同一 `LATEST_API`，按稳定资产名 `solidcraft-windows-x64.msi` 下载升级 |

远程关联要素：

- 更新接口：`https://api.github.com/repos/wodeya163/solidcraft/releases/latest`
- 发行页：`https://github.com/wodeya163/solidcraft/releases/latest`
- 资产固定名：`solidcraft-windows-x64.msi`、`solidcraft-windows-x64-portable.zip`、`SHA256SUMS.txt`、`latest.json`
- 校验：下载后比对同一发行版 `SHA256SUMS.txt` 中的 SHA-256；不匹配则删除临时包并保留原安装
- 日志：`%LOCALAPPDATA%\SolidCraft中文版\自动更新日志.txt`
- 关闭：设置环境变量 `SOLIDCRAFT_UPDATE_CHECK=0`
- 运行中保护：检测到 `solidcraft.exe` 正在运行则推迟安装，避免覆盖使用中的文件

> 说明：本版中文 MSI 内的主程序二进制来自上游 `v0.48.1` 官方发行包，其**内置**更新检查仍指向上游仓库；
> 因此由随包中文更新器负责与本仓库 `releases/latest` 的关联与升级。
> 用本仓库源码重新编译的程序（`update.rs` 已改源）则由内置更新器直接关联本仓库。

## 五、常见问题

- **更新检查失败**：查看自动更新日志；多为网络或 GitHub API 限流（匿名 60 次/小时），下次启动自动重试。
- **升级未完成**：程序正在运行会主动推迟；关闭程序后再点「检查 SolidCraft 更新」。
- **仍是英文界面**：确认从「SolidCraft 中文版」快捷方式启动；或在首选项中把语言改为 `zh`。
- **PowerShell 执行策略拦截**：脚本签名未配置，更新器与计划任务均带 `-ExecutionPolicy Bypass`；若被组织策略禁止，请手动下载 MSI 覆盖安装。
- **便携版不自动检查**：直接双击 `solidcraft.exe` 不会触发启动器，请运行 `启动中文版.ps1` 或「检查 SolidCraft 更新」。
